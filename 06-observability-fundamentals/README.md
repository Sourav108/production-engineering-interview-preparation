# Module 06: Observability Fundamentals

## Learning Objectives

By the end of this module, you will be able to:
- Articulate the definitive difference between **Monitoring** (asking known questions about known failure modes) and **Observability** (interrogating internal system states to debug unknown-unknowns without deploying new code).
- Navigate the full **Telemetry Spectrum**: Metrics, Structured Logs, Distributed Traces, Continuous Profiles, and Audit Events.
- Manage and tame the **High-Cardinality Explosion Problem** in modern time-series databases.
- Follow the evidence-driven troubleshooting flow: **Unknown Failure $\to$ Telemetry $\to$ Evidence $\to$ Diagnosis**.
