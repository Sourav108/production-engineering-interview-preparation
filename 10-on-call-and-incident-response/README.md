# Module 10: On-Call & Incident Management

## Learning Objectives

By the end of this module, you will be able to:
- Lead high-severity production outages using the **SIGNAL Incident Protocol** and the **Incident Command System (ICS)**.
- Delineate the responsibilities of the **Incident Commander (IC)**, **Operations Lead**, **Communications Lead**, and **Scribe**.
- Enforce structured internal and external stakeholder communication cadences during active outages.
- Maintain rigorous timeline discipline and execute rapid mitigation without destroying diagnostic forensics.
