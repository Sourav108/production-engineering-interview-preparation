# Module 14: Load Testing, Stress Testing & Benchmarking

## Learning Objectives

By the end of this module, you will be able to:
- Formulate and execute the 4 core performance testing archetypes: **Load Testing, Stress/Breakpoint Testing, Soak (Endurance) Testing, and Spike Testing**.
- Design scriptable load test scenarios using **k6** or **Vegeta** incorporating realistic user think time and authentic payload distributions.
- Eliminate benchmarking pitfalls: **Coordinated Omission**, JVM warmup bias, client-side resource starvation, and fabricated metrics.
- Produce evidence-driven performance audit reports with exact percentile breakdowns.
