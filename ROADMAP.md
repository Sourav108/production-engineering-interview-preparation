# Six-Week Production Engineering Study Roadmap

A rigorous, full-time or part-time preparation schedule designed to take engineers from foundations to Staff-level production mastery.

$$\mathbf{Learn} \to \mathbf{Measure} \to \mathbf{Debug} \to \mathbf{Operate} \to \mathbf{Practice} \to \mathbf{Interview} \to \mathbf{Review}$$

---

## 📅 Weekly Schedule Overview

| Week | Focus Area | Modules Covered | Key Milestones & Practical Outputs |
| :-: | :--- | :-: | :--- |
| **Week 1** | **Host, Systems & Network Foundations** | Modules 01–05 | Master Linux CLI triage tools, diagnose OOM kills, trace DNS/TLS request paths, design health probes |
| **Week 2** | **Observability, Monitoring & Incident Management** | Modules 06–10 | Build OpenTelemetry tracing, configure multi-window burn rate alerts, draft SLO error budget policies, lead mock incidents |
| **Week 3** | **Performance, Debugging & Capacity Engineering** | Modules 11–14 | Master hypothesis-driven debugging, decompose latency tails, forecast resource headroom, run k6 load tests |
| **Week 4** | **Resilience Patterns, Caching & Distributed Systems** | Modules 15–21 | Implement circuit breakers & adaptive rate limiters, prevent cache stampedes, triage DB pool exhaustion, contain cascades |
| **Week 5** | **Release Safety, DR, Security & Chaos** | Modules 22–28 | Design canary rollouts, prove multi-region disaster recovery, execute chaos experiments, write blameless postmortems |
| **Week 6** | **Interview Question Bank & Production System Design** | Modules 29–30 | Complete 500 interview questions, design 5 reference production systems, solve 50 incident scenarios |

---

## 🗓️ Daily Study Protocol (2–3 Hours / Day)

- **First 45 mins**: Read module theory, mental models, and failure mode documentation.
- **Next 45 mins**: Execute hands-on failure injection lab, observe telemetry, apply mitigations.
- **Next 30 mins**: Solve 10–15 technical interview questions from [Module 29](29-production-engineering-interview-questions/).
- **Final 15 mins**: Review runbooks, postmortems, and update notes.
